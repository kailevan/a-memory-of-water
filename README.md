# A memory of water

**Walk through it: https://kailevan.github.io/a-memory-of-water/**

A walkable memory of a fragrance. You start inside a high-school classroom that smells of the perfume, walk up the aisle, and the room slowly gives way to the fragrance itself.

Kai Levan · IFM Paris · Beauty and Well-Being Management · 2026

## Walking

- **Desktop:** WASD to move, mouse to look, Space to jump, Shift to run, Esc to pause.
- **Phone:** left thumb walks and turns (push to the edge to run), drag anywhere else to look around.

Works best in a recent Chrome, Edge or Safari. The first visit downloads about 170 MB of scene files.

## How it was built

The world runs live in the browser. It is made with [three.js](https://threejs.org) and drawn with WebGPU. The rocks, plants and ingredients are 3D scans of real objects. The sound combines nature recordings with a school bell and footsteps generated using the Web Audio API, mixed live as you walk.

This repository holds only the built site. The project source is private.
